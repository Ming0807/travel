## 3. Stakeholder Needs Analysis

### 3.1 Tourist (Thai Domestic)

**Context:** Thai tourists visiting from other provinces on weekends or holidays.

**Needs:**
- Quick and easy certificate creation
- Thai language interface
- Mobile-friendly experience
- No mandatory registration
- Optional LINE integration for passport persistence
- Visual travel memory

**Pain Points:**
- Long forms are annoying during trips
- Forced login before seeing value
- Unclear data usage

### 3.2 Tourist (Foreign)

**Context:** International visitors, especially from Malaysia and other countries.

**Needs:**
- English language interface
- No LINE dependency
- Guest mode that works without Thai services
- Email option for passport recovery
- Clear privacy explanation

**Pain Points:**
- Thai-only interfaces
- Mandatory LINE login
- Complex forms with Thai-specific fields

### 3.3 Tourism Staff

**Context:** Staff at tourism offices or attraction sites managing content.

**Needs:**
- Easy attraction content management
- Photo spot and QR code management
- Visit record viewing with filters
- Data export for reporting
- Clear status indicators

**Pain Points:**
- Complex admin interfaces
- No search or filter capabilities
- Loading all records without pagination

### 3.4 System Administrator

**Context:** Technical staff managing system operations.

**Needs:**
- User and role management
- Audit log access
- System configuration
- Security monitoring
- Data backup awareness

**Pain Points:**
- Missing audit trails
- No role-based access control
- Exposed sensitive settings

### 3.5 Researcher/Planner

**Context:** Academic researchers and provincial tourism planners.

**Needs:**
- Reliable dashboard metrics
- Filterable data views
- Exportable datasets
- Clear metric definitions
- Historical trend analysis

**Pain Points:**
- Undefined or inconsistent metrics
- No data export capability
- Dashboard without planning value

### 3.6 Provincial Tourism Office

**Context:** Government office responsible for tourism promotion and planning.

**Needs:**
- Province-level statistics
- Attraction performance ranking
- Satisfaction overview
- Spending distribution
- Evidence for budget proposals

### 3.7 Local Community

**Context:** Community enterprises, homestays, and local businesses.

**Needs:**
- Visibility for community attractions
- Tourist traffic data
- Spending insights
- Promotion opportunities
